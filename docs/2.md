Analisis dan implementasikan pengembangan fitur Export Hasil Nilai pada repository lokal examsmpalfa.

Stack: Rust Axum, SQLx, MariaDB, Tera, HTMX.

Fokus perubahan:
- src/controllers/guru/ujian/nilai.rs
- templates/guru/ujian/nilai_kelas_mapel.html
- templates/guru/ujian/_nilai_kelas_mapel_table.html
- src/routes/guru_routes.rs
- File pendukung lain hanya jika diperlukan.

Jangan mengubah autentikasi, logika ujian, perhitungan nilai, maupun perubahan sebelumnya yang sudah berjalan baik.

### 1. Tambahkan informasi ujian pada export

Saat ini header Excel hanya berisi:
- Tahun
- Kelas
- Mata Pelajaran

Tambahkan:
- Judul Ujian (`ujians.title`)
- Deskripsi Ujian (`ujians.description`)

Contoh:

REKAP HASIL NILAI UJIAN

Tahun: 2026 / 2027
Kelas: 8A
Mata Pelajaran: Informatika
Judul Ujian: Penilaian Harian Analisis Data
Deskripsi: Evaluasi materi analisis data dan dasar Excel

Audit relasi `ujians`, `hasil_nilais`, dan `ujian_pengerjaans` untuk memastikan metadata berasal dari ujian yang benar.

PENTING: Filter saat ini adalah tahun, kelas, dan mata pelajaran. Satu mata pelajaran mungkin mempunyai beberapa ujian.

Tambahkan filter ujian yang bergantung pada tahun dan mata pelajaran, sehingga judul, deskripsi, jawaban, dan nilai tidak tercampur dari ujian berbeda.

Pertahankan perilaku rekap lama ketika ujian tidak dipilih. Jangan mengubah nilai agregat yang sudah berjalan.

Untuk export jawaban, wajib memilih satu ujian secara eksplisit. Jangan mengambil ujian pertama secara acak.

### 2. Buat dua tombol export

Pada halaman Hasil Nilai tampilkan:

1. Export Nilai
2. Export Nilai + Jawaban

Export Nilai:
- Pertahankan seluruh kolom dan logika export lama.
- Tambahkan judul dan deskripsi jika satu ujian dipilih.
- Jika filter mencakup beberapa ujian, tulis keterangan "Rekap seluruh ujian" dan jangan mengarang judul.
- Tetap dapat digunakan seperti sebelumnya.

Export Nilai + Jawaban:
- Gunakan filter tahun, kelas, mata pelajaran, dan ujian.
- Wajib ada ujian terpilih.
- Export seluruh siswa sesuai filter kelas dan tahun.
- Gunakan urutan siswa seperti export lama.
- Nilai dan jawaban harus konsisten dengan ujian terpilih.

Tambahkan route export baru atau parameter mode yang jelas tanpa merusak endpoint lama.

### 3. Struktur kolom Excel Nilai + Jawaban

Kolom tetap:

No | NIS | Nama | Kelas | Benar | Salah | Nilai PG | Nilai Uraian | Total Nilai

Setelah itu tambahkan dua kolom untuk setiap nomor soal:

Soal 1 - Jawaban
Soal 1 - Benar
Soal 2 - Jawaban
Soal 2 - Benar
Soal 3 - Jawaban
Soal 3 - Benar

Dan seterusnya sesuai jumlah soal ujian.

Gunakan `ujian_soals.urutan` sebagai urutan soal, bukan urutan ID pada tabel `soals`.

Jika ujian mempunyai 30 soal, berarti ada 60 kolom tambahan.

### 4. Aturan pengisian jawaban

Ambil jawaban dari `ujian_jawabans` berdasarkan `ujian_id`, `nis`, dan `soal_id`.

Ambil detail soal dari `soals` dan relasi `ujian_soals`.

Untuk pilihan ganda biasa:

Jika jawaban tersimpan adalah A, jangan tuliskan hanya huruf A.

Ambil isi `soals.opsi_a`.

Contoh:
- Pilihan siswa: A
- Isi opsi A: "Menggunakan rumus IF"
- Isi Excel: "Menggunakan rumus IF"

Demikian juga untuk opsi B, C, D, atau opsi lain yang memang didukung schema.

Untuk soal uraian:
- Tuliskan isi `ujian_jawabans.jawaban_uraian` secara langsung.
- Pertahankan isi jawaban siswa, termasuk kalimat panjang.
- Pastikan karakter khusus tidak merusak Excel.

Untuk pilihan ganda kompleks:
- Jika siswa memilih lebih dari satu opsi, tampilkan seluruh teks opsi yang dipilih.
- Pisahkan secara jelas, misalnya dengan `; `.
- Pertahankan urutan opsi.
- Jangan hanya menampilkan kode A,B,C.

Untuk soal benar/salah:
- Audit format jawaban yang tersimpan.
- Tampilkan isi pernyataan dan pilihan Benar/Salah masing-masing sesuai jawaban siswa.
- Jangan menafsirkan format jawaban secara sembarangan.

Gunakan fungsi pemetaan jawaban yang sesuai dengan format penyimpanan asli masing-masing kategori soal.

### 5. Aturan kolom Benar

Untuk pilihan ganda biasa:
- 1 = jawaban benar
- 0 = jawaban salah

Gunakan hasil evaluasi jawaban yang sudah tersimpan, bukan membuat logika penilaian baru.

Untuk pilihan ganda kompleks dan benar/salah:
- Audit mekanisme penilaian yang sudah berlaku.
- Jika penilaian memiliki partial credit, jangan menganggap nilai parsial sebagai benar penuh.
- Kolom Benar bernilai 1 hanya jika seluruh jawaban sesuai kunci; selain itu 0.
- Jika diperlukan, gunakan fungsi evaluasi yang sudah ada tanpa mengubah perhitungan skor.

Untuk uraian:
- Jangan mengubah penilaian uraian menjadi benar/salah secara otomatis.
- Jika tidak ada status benar/salah yang eksplisit, kosongkan kolom Benar untuk uraian.
- Nilai uraian tetap tercermin pada kolom Nilai Uraian.

Jika siswa belum menjawab suatu soal:
- Kolom Jawaban kosong.
- Kolom Benar kosong, bukan 0.

Jika siswa menjawab tetapi salah:
- Kolom Jawaban menampilkan jawaban siswa.
- Kolom Benar berisi angka 0.

### 6. Konsistensi nilai dan data

Audit sumber `hasil_nilais` karena saat ini nilai diambil berdasarkan NIS, mata pelajaran, dan tahun.

Jangan menggunakan nilai agregat mata pelajaran sebagai nilai satu ujian apabila terdapat lebih dari satu ujian.

Periksa apakah schema menyimpan nilai per ujian secara langsung.

Jika tidak, gunakan hasil `ujian_jawabans`, `ujian_pengerjaans`, dan data penilaian yang tersedia untuk memperoleh rekap per ujian sesuai logika penilaian asli.

Jangan mengarang atau menduplikasi nilai.

Untuk siswa yang belum mengerjakan ujian:
- Identitas siswa tetap muncul.
- Kolom jawaban kosong.
- Nilai yang belum tersedia jangan dipaksa menjadi 0.

Untuk siswa yang sudah mengerjakan:
- Tampilkan jawaban yang tersimpan.
- Gunakan nilai yang sesuai dengan status dan hasil penilaiannya.

### 7. Format Excel

Saat ini export menggunakan Excel XML (.xls).

Pertahankan format tersebut jika sudah mencukupi dan tetap kompatibel dengan Microsoft Excel maupun LibreOffice.

Jika jumlah kolom atau panjang jawaban memerlukan penyesuaian, lakukan tanpa merusak format export sebelumnya.

Pastikan:
- NIS diekspor sebagai teks.
- Nilai diekspor sebagai angka.
- Status Benar diekspor sebagai angka 1 atau 0.
- Jawaban diekspor sebagai teks.
- XML escape aman.
- Teks panjang tidak terpotong.
- Tidak terjadi Excel formula injection dari jawaban siswa.
- Nama file mencantumkan kelas, mata pelajaran, tahun, dan judul ujian jika dipilih.

Contoh:
hasil-nilai-jawaban-8A-informatika-penilaian-harian-2026-2027.xls

### 8. Efisiensi query

Hindari N+1 query.

Ambil:
1. Daftar siswa kelas.
2. Metadata ujian dan urutan soal.
3. Seluruh jawaban peserta untuk ujian terpilih.
4. Data nilai yang sesuai.

Gunakan HashMap atau struktur Rust yang sesuai untuk memetakan jawaban berdasarkan NIS dan soal_id.

Jangan menjalankan query database untuk setiap sel Excel.
